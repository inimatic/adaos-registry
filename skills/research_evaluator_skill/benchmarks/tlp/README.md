# TLP calibration instance

This directory contains evaluator-owned fixtures for the first C0-C4 research
compiler calibration. The candidate-visible conformance fixture and C4 scaffold
describe observable contracts. The hidden rubric and legacy oracle are never
placed in a candidate artifact view or instruction packet.

The frozen task points to the accepted `tlp_compiler_calibration` Research
Compilation and AutomationBrief. The historical written review is visible only
to C1 as `reviewed_prose`; the original notebook is admitted through the
direction skill's audience-filtered artifact group for every arm.

The legacy oracle is not a gold implementation. It supports evaluator-side gap
classification only. Passing requires evidence-valid completion against the
frozen protocol, not similarity to an earlier codebase.
