# TLP structured proof runner

This direction-owned AdaOS skill provides `adaos.research.runner.v1` for the
accepted paired STL-10 comparison. ResearchManager owns attempt orchestration,
tracking, ingestion, and finalization; this package owns only preparation,
execution outputs, collection, artifact verification, and immutable dataset
bindings.

Notebook outputs remain untrusted exploratory source material. A preflight run
is workflow evidence only and never supports a scientific claim.
